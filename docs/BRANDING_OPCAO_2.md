# Compras da JuRe — Identidade visual Opção 2

Aplicada à versão 2.8.7 do aplicativo.

## Direção
- Azul tecnológico como cor principal.
- Laranja/âmbar para destaque e confirmação.
- Ícone: carrinho + cupom + check.
- Assinatura: **Seus cupons em boas mãos**.

## Ativos
- `assets/jure-icon.svg` — vetor do ícone.
- `assets/jure-logo.svg` — vetor da marca completa.
- `assets/icon-192.png` — ícone PWA 192×192.
- `assets/icon-512.png` — ícone PWA 512×512.
- `assets/apple-touch-icon.png` — iOS 180×180.
- `assets/favicon.png` / `favicon.ico` — favicon.
